### [SkillBridge — Skill & Internship Matching Platform](https://github.com/alishacreates/SkillBridge)

A platform connecting student skill profiles with internship opportunities, based on Smart India Hackathon 2026 problem statement **SIH26044**.

**Stack:** Next.js · TypeScript · Express.js · PostgreSQL · Prisma · Zod · JWT · Tailwind CSS

**Status:** In development — backend foundation implemented; authentication and matching workflows in progress.

- Designed a normalized PostgreSQL data model for students, recruiters, skills, opportunities, applications, assessments, and learning resources.
- Built a layered Express.js backend with centralized validation, error handling, typed configuration, health checks, and automated API tests.
- Implementing JWT authentication and role-based access control for students, recruiters, and administrators.
- Developing skill matching and gap analysis using required and preferred skills, eligibility, target-role relevance, and assessment performance.

[Explore the repository →](https://github.com/alishacreates/SkillBridge)
